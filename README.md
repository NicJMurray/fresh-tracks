# Fresh Tracks

Music discovery at https://fresh.njmurray.com, built around overlap between frequently updated Spotify playlists. The repository is https://github.com/NicJMurray/fresh-tracks.

## What it does

- Pins Nic's five default seeds. The repeated PRIVATE RADIO link is deduplicated.
- Accepts additional public Spotify playlist links and saves that collection in the browser. Copy link transfers the collection to another device without an account.
- Ranks all artists by distinct seed playlists, then track appearances; shows the top ten by default.
- Ranks tracks appearing in at least two seeds, deduplicating by Spotify track ID and counting each track once per seed.
- Credits every artist exposed in the preview, including collaborators. Artist identity uses normalized names because previews do not expose artist IDs.
- Prefills discovery with the three leading artists and shared tracks. Search uses OR within each field, then verifies names in current Spotify previews. Results already in the seeds are excluded. Add a result to recalculate overlap.
- Stores daily snapshots in Cloudflare D1. After a week, the same seed collection can be compared with its earlier rankings. An artist entering the top ten gets a badge; the first baseline is never labelled as a new arrival.

## Data limits

This first version reads public Spotify embed metadata, without Spotify credentials, login, playback, or private playlists. Public previews expose **at most 100 tracks per playlist**. Full coverage is unverified even below that limit. The UI labels previews and capped seeds; rankings describe the visible sample. Different Spotify track IDs are distinct recordings, even when titles match.

Previews do not expose track-added dates or a reliable last-updated date. Fresh Tracks records observed content changes between its own snapshots. Search-description update hints are explicitly unconfirmed. A checked timestamp means the preview was fetched, not that its owner updated it. Three initial default seeds reach the preview limit. A future official API adapter will need a Spotify developer application and suitable access; signing in alone does not remove Spotify's API restrictions.

Discovery reuses the existing `playlist.njmurray.com/api/playlists` Pages Function, keeping its Google credentials in that application. Google indexing can miss playlists or return outdated descriptions. Only candidates whose visible tracks match are shown. Search can return no verified results even when Google found links.

Seeds are public data. Extra seed choices live on the device; shared collection links explicitly contain their playlist IDs. There are no user accounts or private Spotify data in this version.

## Development

Node 22 or newer:

```sh
npm ci
npm run types
npm run db:local
npm run dev
npm run build
```

`npm run build` type checks, runs the Node regression tests, and dry-runs Wrangler's Worker bundle. `public/` is the only static asset directory. The Worker, docs, database, and dependencies are never public files. Runtime bindings are generated by `wrangler types` rather than maintained by hand.

## Structure

| Path | Purpose |
| --- | --- |
| `public/` | Responsive dashboard, browser state and forms |
| `src/catalog.ts` | Permanent seed list, URL validation and data model |
| `src/spotify.ts` | Bounded public-preview parsing |
| `src/store.ts` | D1 caching, snapshots, weekly lookback and daily refresh |
| `src/signals.ts` | Distinct-playlist overlap and rank comparison |
| `src/discovery.ts` | Existing finder integration and verified candidates |
| `src/worker.ts` | HTTP API and scheduled refresh |
| `migrations/` | Versioned D1 schema |
| `test/` | Identity, aggregation, badges, parsing and request-bound tests |

Snapshots last 35 days. Normal visits reuse one-hour previews; explicit refresh still reuses snapshots younger than 15 minutes. Failed refreshes retain and label saved previews. Seeds with no readable preview are excluded; weekly badges are suppressed when any seed is unavailable or stale. No paid Spotify service or third-party data reseller is required.
